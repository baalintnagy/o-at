O-NEC, O-NR, O-AUD-TX, O-AUD-RX and O-AUD-A for Windows (x64)
==============================================================

Contents
--------
VST3\O-NEC.vst3, O-NR.vst3, O-AUD-TX.vst3, O-AUD-RX.vst3, O-AUD-A.vst3   VST3 plugins
CLAP\O-NEC.clap, O-NR.clap, O-AUD-TX.clap, O-AUD-RX.clap, O-AUD-A.clap    CLAP plugins
O-AUD-RX.exe                    Plays a bus on any output device
O-AUD-TX.exe                    Sends an input, an output or an application to a bus
O-AUD-A-standalone.exe          Analyzes an audio input device
O-NEC-standalone.exe            O-NEC without a plugin host
O-NR-standalone.exe             O-NR without a plugin host
install.cmd, uninstall.cmd      Install or remove everything (they run install.ps1)

Install
-------
Close plugin hosts and O-AT applications, then double-click install.cmd. It copies:

- the VST3 and CLAP plugins to C:\Program Files\Common Files\VST3 and ...\CLAP
  (Windows asks for administrator rights for this step only),
- the applications to %LOCALAPPDATA%\Programs\O-AT, with Start Menu shortcuts under O-AT.

Then rescan plugins in your host. They are listed under the vendor "o-at". Run
install.cmd from a newer release to update; uninstall.cmd removes everything except the
applications' settings. From PowerShell, install.ps1 also takes -SkipPlugins, -SkipApps
and -Uninstall (Get-Help .\install.ps1 for details).

To install by hand instead, copy the folders in VST3 to
C:\Program Files\Common Files\VST3 and the files in CLAP to
C:\Program Files\Common Files\CLAP (both need administrator rights); the applications
run from any folder.

O-NEC, O-AUD-TX and O-AUD-RX replace the earlier ONEC, AUD-TX and AUD-RX. They have
new plugin IDs, so hosts list them as new plugins: replace the earlier ones in your
sessions, then delete ONEC.vst3, AUD-TX.vst3, AUD-RX.vst3 and ONEC.clap.

Route audio between hosts and devices
-------------------------------------
1. Insert O-AUD-TX where audio should leave a host. It names its bus Bus 1, Bus 2 and
   so on; type another name, or click EDIT if the host keeps your keystrokes
   (for example Ableton Live).
2. Play the bus with the O-AUD-RX plugin in any host, or with O-AUD-RX.exe on any output
   device: pick the bus from the list or enter its name.
3. Raise Latency in O-AUD-RX if its Dropouts counter keeps rising.

Senders and receivers must run on the same computer, as the same Windows user and at
the same permission level.

O-AUD-RX.exe remembers its bus, device and settings in %APPDATA%\O-AUD-RX\settings.ini
and accepts --bus NAME and --device NAME.

O-AUD-TX.exe sends routes, each from one source to its own bus: an input device,
everything an output device plays, or what a single application plays. + ADD and REMOVE
under ROUTES add and stop routes; pick the selected route's source under AUDIO SOURCE.
APPLICATIONS lists the programs with audio; picking one sends that program and its child
processes (Windows 10 version 2004 or later) and follows it when it restarts. Don't play
a bus on the output device it captures, which feeds back. It remembers its routes in
%APPDATA%\O-AUD-TX\settings.ini and accepts --bus NAME, --input NAME, --loopback NAME
("default" selects the system default device) and --application EXE. A bus and a source
make a route; repeat them for more routes, for example
--bus Browser --application brave.exe --bus Voice --input default.
O-AUD-TX.exe replaces O-AUD-TX-standalone.exe; install.cmd deletes the earlier file.

Remove noise
------------
Insert O-NR on any track. Play a passage where only the noise is heard, press LEARN,
then press STOP LEARNING: that spectrum becomes the noise profile, stored with the
session. Raise Reduction for more attenuation and Threshold to treat more as noise;
LISTEN REMOVED plays what is taken away. Without a profile, or with Adaptive, O-NR
tracks steady noise under the signal by itself. Higher Resolution separates hum and
other steady tones better but adds delay, which hosts compensate.

Analyze audio
-------------
Insert O-AUD-A anywhere in a chain; it passes the audio through unchanged. Its pages
show a spectrum analyzer, a sonogram, a stereo imager, an oscilloscope, an EBU R 128
loudness meter with target presets and a PLATFORMS table of what streaming platforms'
normalization does to the track, and 3D spectrum and stereo views; SPECTRAL overlays the
waveform on the sonogram. OVERVIEW
shows the views you switch on: drag a view's title to move it and the gaps between views
to resize them. Click the button at the right of a view's header, or right-click the diagram, for its SETTINGS and COLORS; THEME colors the controls. Drag the window's lower
right corner to resize it, or click FULL SCREEN (F11) to take it full screen; RESTORE or
Esc brings it back.

SOURCES adds buses from O-AUD-TX next to the input, each in its own color, with its
loudness in the panel. Every view picks its signals under SIGNALS at the top of its
settings, INPUT and each bus; several are overlaid in their colors. Every view shows
every bus until you switch it off there. MATCH LEVEL compares spectrum curves at equal loudness, MASKING shades
the frequencies where two curves are about equally loud. Put
O-AUD-TX on the tracks to compare and O-AUD-A on the master, or send a reference track
from its player with an O-AUD-TX.exe route (APPLICATIONS, or its output device).

O-AUD-A-standalone.exe analyzes an input device and plays nothing back: run it with
--backend wasapi (see --help for devices and rates).
